--bridge-debug — when the Lua↔Python bridge drops a payload

The bridge between Lua and Python rejects payloads it cannot convert (non-JSON-compatible values crossing a wire that must stay JSON). When that happens silently, the symptom is a QA action that "did nothing".

--bridge-debug makes it loud: the failing payload is dumped and a system event recorded (pinned) — the first diagnostic an agent should turn on for a mystery no-op. The discipline behind it: everything crossing the bridge is JSON-compatible; never cross a Lua function reference (AGENTS.md). Off by default, one flag when things smell.
