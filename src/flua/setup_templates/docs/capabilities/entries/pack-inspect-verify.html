pack, inspectFQA, and pack --verify — trust the artifact

The package pipeline an agent should run before claiming a QA is ready:

  • flua --tool pack main.lua — builds the .fqa (package values baked, --%%file extras included, identity properties carried).
  • flua --tool inspectFQA my.fqa [--json] — what the package actually contains: inventory, variables, leak scan. The second time agents asked for this, it became a tool.
  • flua --tool pack qa.lua --verify — pack, then inspect the artifact in one step (placeholder/leak checks).

Agents want to see what got packed rather than trust it — the --verify round trip closes that loop. Pair with flua --check file.lua for static analysis before packing.
